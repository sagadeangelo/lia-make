# 🧩 LIA-Make

> **Build software visually. Let AI build with you.**

LIA-Make is an experimental **AI-powered visual development environment** designed to transform application development into a visual, node-based experience.

Instead of writing every piece of an application manually, developers can construct application logic using a visual graph of interconnected nodes — while LIA assists with architecture, logic, UI and automation.

---

## 🚀 Vision

Traditional development separates developers from the architecture of the application.

LIA-Make aims to make that architecture visible.
