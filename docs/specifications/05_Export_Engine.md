# Introducción

El Export Engine (LEE - LIA Export Engine) es el sistema responsable de transformar un proyecto LUJ en un proyecto completamente funcional.

No genera únicamente código.

Construye proyectos completos.

Incluyendo.

Código.

Documentación.

Configuración.

Assets.

Pruebas.

Deploy.

Todo listo para continuar desarrollándose.

# Responsabilidades que NO tiene

No interpreta LUJ.

No toma decisiones de negocio.

No modifica el Canvas.

No modifica nodos.

Solo construye proyectos.

---

# Regla Suprema

Todo proyecto exportado debe sentirse como si hubiera sido desarrollado manualmente por un equipo profesional.

Nunca debe parecer código generado.
