# Introducción

El Canvas es el centro absoluto de LIA-Make.

No representa código.

Representa la arquitectura de una aplicación.

Cada elemento visual corresponde a un componente real del proyecto.

El usuario nunca programa directamente.

Construye.

---

# Objetivo

Permitir que cualquier persona comprenda cómo funciona un software mediante una representación completamente visual.

---

# Filosofía

El Canvas debe sentirse como una mesa de trabajo.

No como un IDE.

Debe invitar a experimentar.

Mover.

Probar.

Equivocarse.

Crear.
