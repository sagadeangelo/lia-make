# 02 — Node Categories

> Every node belongs to a family.
>
> Every family has its own personality.

---

# Introduction

As LIA-Make grows, hundreds of nodes will become available.

Without a clear organization the Forge quickly becomes overwhelming.

Categories solve this problem.

Each category represents a major area of application development.

Each category has:

• Identity

• Color

• Iconography

• Sound

• Personality

• Connection Style

• Typical Usage

The user should recognize a node family instantly.

---

# Visual Language

Each category owns a unique visual identity.

Users should understand a workflow simply by observing colors.

Reading labels should become optional.

# Design Rules

A category must:

✓ Have a unique color.

✓ Have a recognizable icon.

✓ Have its own animation style.

✓ Have a unique connection color.

✓ Have a distinctive hover effect.

✓ Have an identifiable sound.

✓ Feel different from every other category.

---

# The Goal

The user should recognize an application simply by looking at its colors.

The visual language becomes universal.

Labels become secondary.

---

# Final Thought

Categories are more than organization.

They are the visual vocabulary of LIA-Make.

Every new node enriches that language.

Every workflow becomes a story told through colors, motion and intelligent connections.
