# 06 — Node Connections

> Connections are not lines.
>
> Connections are living flows of information.

---

# Introduction

Most visual editors represent connections as simple lines.

LIA-Make does not.

A connection represents a relationship.

A dependency.

A communication channel.

A living flow of information.

Connections deserve the same level of care as nodes.

---

# Philosophy

Nodes are the organs.

Connections are the nervous system.

Without connections,

there is no application.

Only isolated components.

---

# The Creator Experience

Connecting two nodes should feel satisfying.

It should feel like assembling two precision-engineered parts.

Not drawing a line.

The user should immediately know when:

✓ A connection is valid.

✓ A connection is incomplete.

✓ A connection is impossible.

Without reading messages.

# Connection Shape

Connections should never be rigid.

Preferred

Smooth Bézier curves.

Natural flow.

Organic movement.

Avoid

Sharp angles.

Perfectly straight lines.

Mechanical appearance.

---

# Dynamic Connections

Connections are alive.

When idle

Soft glow.

Very subtle.

When selected

Glow increases.

Width slightly expands.

When hovered

Connection becomes brighter.

Endpoints illuminate.

---

# Animated Flow

During execution,

energy travels through the cable.

Particles move.

The creator literally watches information flowing.

The application becomes understandable.

---

# Magnetic System

Every port has magnetic attraction.

When a compatible connector approaches,

the destination softly attracts the cable.

The user feels guidance.

Not restriction.

---

# Snap Distance

Connections automatically snap when entering the magnetic zone.

The creator should never fight the interface.

The interface assists.

---

# Successful Connection

Visual

Quick light pulse.

Magnetic lock animation.

Connection settles naturally.

Audio

Signature magnetic metallic click.

Feeling

"This belongs here."

---

# Invalid Connection

Visual

Connection retracts.

Destination briefly flashes red.

Very small shake.

Audio

Soft dry click.

Feeling

"This does not fit."

Never

"You made a mistake."

---

# Incomplete Connection

Visual

Amber pulse.

Ghost cable.

Missing requirement badge.

Audio

Neutral confirmation.

Feeling

"Almost."
