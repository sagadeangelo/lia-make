# 04 - Design System

> "La interfaz debe desaparecer para que la creatividad aparezca."

---

# Introducción

Este documento define el lenguaje visual de LIA-Make.

Ningún componente podrá diseñarse fuera de estas reglas.

El objetivo es construir una experiencia consistente, elegante y viva.

---

# Filosofía Visual

LIA-Make no debe sentirse como un IDE.

Debe sentirse como un estudio creativo.

El usuario debe tener la sensación de estar construyendo el futuro.

Cada elemento debe transmitir:

• simplicidad

• tecnología

• elegancia

• claridad

• movimiento

---

# Principios

## Todo respira

Nada completamente estático.

Pequeñas animaciones.

Glow.

Movimiento suave.

Vida.

---

## Todo tiene profundidad

Sombras.

Cristal.

Blur.

Capas.

Iluminación.

---

## La información más importante siempre destaca.

Nunca mediante colores agresivos.

Sino mediante:

• tamaño

• iluminación

• contraste

---

## Oscuro primero

LIA-Make está diseñado primero para Dark Theme.

Posteriormente existirá Light Theme.
