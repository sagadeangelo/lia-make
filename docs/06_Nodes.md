# 06 - Nodes

> "Cada nodo representa una idea. La conexión entre ellos representa un software."

---

# Introducción

Los nodos son la unidad fundamental de construcción dentro de LIA-Make.

Todo lo que existe dentro de una aplicación será representado mediante nodos.

No representan código.

Representan conceptos.

El objetivo es que cualquier persona pueda comprender la arquitectura de un software sin necesidad de saber programar.

---

# Filosofía

Los usuarios no deben pensar en:

- clases
- archivos
- paquetes
- funciones

Deben pensar en:

- pantallas
- usuarios
- datos
- procesos
- servicios
- inteligencia artificial

---

# ¿Qué es un Nodo?

Un nodo es una representación visual de un componente del sistema.

Cada nodo tiene una responsabilidad específica.

Cada nodo puede conectarse con otros.

Cada nodo puede ser explicado por la IA.

---
