# 📘 LIA-Make

# 03 - User Journey

> "Crear software debe sentirse tan natural como dibujar una idea."

---

# Introducción

Este documento describe el recorrido completo del usuario dentro de LIA-Make.

No representa pantallas.

Representa emociones, decisiones y experiencias.

Cada nueva función deberá respetar este recorrido.

---

# Objetivo

Cuando un usuario cierre LIA-Make deberá pensar:

> "No sabía programar...
>
> ...y aun así construí mi propia aplicación."

# Etapa 1

## Bienvenida

### Objetivo

Eliminar el miedo.

El usuario no debe sentirse frente a un IDE.

Debe sentirse entrando a un estudio creativo.

---

La pantalla mostrará:

• Logo

• Avatar IA

• Últimos proyectos

• Botón "Crear"

• Inspiración

• Plantillas

---

El compañero IA dirá algo como:

> "¡Hola!

> ¿Qué vamos a construir hoy?"

---

# Etapa 2

## La Idea

Aquí comienza todo.

No se habla de Flutter.

No se habla de Backend.

No se habla de APIs.

Solo de la idea.

Ejemplo.

> Quiero crear una aplicación para una veterinaria.

---

La IA hará preguntas inteligentes.

- ¿Será móvil?
- ¿Necesitará usuarios?
- ¿Habrá pagos?
- ¿Necesita administración?
- ¿Quieres venderla?

---

Al finalizar.

La IA genera un primer borrador.

---

# Etapa 3

## Arquitectura Inteligente

Antes del Canvas.

La IA presenta un resumen.

Ejemplo.

Tu aplicación necesitará:

✔ Login

✔ Usuarios

✔ Agenda

✔ Inventario

✔ API

✔ Base de Datos

✔ Panel Administrativo

✔ Recordatorios

---

El usuario puede.

Aceptar.

Eliminar.

Agregar.

Modificar.

---

# Etapa 4

## El Canvas

Aquí comienza la construcción.

El usuario observa aparecer automáticamente los primeros nodos.

No comienza desde cero.

---

El Canvas tendrá.

Panel izquierdo

Canvas

Panel IA

Prompt

Inspector

---

Todo será editable.

---

# Etapa 5

## Construcción

Aquí el usuario comienza a crear.

Cada nuevo nodo tendrá una explicación sencilla.

Ejemplo.

Pantalla

Base de Datos

API

Usuarios

Pagos

Notificaciones

---

El usuario arrastra.

La IA conecta.

---

Cada acción deberá sentirse natural.

---

# Etapa 6

## Aprendizaje

Mientras construye.

La IA explicará.

¿Por qué existe una API?

¿Por qué necesitamos una Base de Datos?

¿Qué hace este nodo?

¿Qué significa JWT?

Todo utilizando lenguaje sencillo.

---

# Etapa 7

## Simulación

El usuario puede probar su aplicación.

Sin exportarla.

Sin compilar.

Sin instalar nada.

Simplemente presiona.

▶ Probar

Y la aplicación funciona.

---

# Etapa 8

## Corrección Inteligente

Cuando existe un problema.

Nunca aparecerá un error técnico.

Ejemplo.

Incorrecto

Null Pointer Exception

Correcto

"La pantalla Perfil está esperando información del usuario."

---

La IA propondrá soluciones.

Nunca solo mostrará el problema.

---

# Etapa 9

## Centro de Lanzamiento

Cuando la aplicación está lista.

El usuario entra al Centro de Lanzamiento.

Aquí encuentra.

✔ README

✔ Capturas

✔ Video

✔ Banner

✔ Descripción

✔ Tecnologías

✔ Costos

✔ Precio sugerido

✔ Icono

Todo generado automáticamente.

---

El usuario puede modificar cualquier elemento.

O aceptar las propuestas de la IA.

# Filosofía del Recorrido

El usuario nunca debe sentir que está programando.

Debe sentir que está construyendo algo propio.

La IA nunca deberá quitarle esa sensación.

# Regla Principal

La IA trabaja.

El usuario crea.
